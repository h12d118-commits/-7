## 1. 📌 프로젝트 개요 및 배경

- **프로젝트명**: 틴코스 AI (TeenCos AI: Teen Cosmetics Machine Learning Recommendation & Comparison System)
- **개발 배경**:  
  사춘기 청소년 시기는 피지 분비, 여드름, 좁쌀 트러블 등 피부 고민이 급증하는 시기입니다.  
  하지만 10대 학생들은 **한정된 용돈**으로 화장품을 구매해야 하는 경제적 제약이 존재하며, SNS 과장 광고나 무분별한 랭킹으로 인해 피부에 맞지 않거나 용량 대비 비싼 화장품을 구매하여 부작용 및 금전적 낭비를 겪는 사례가 빈번합니다.
- **개발 목적**:  
  대한민국 대표 화장품 정보 플랫폼인 **화해(Hwahae)**의 공신력 있는 데이터(20가지 주의성분, 식약처 알레르기 유발성분, 화해 평점 및 연령대별 실구매자 리뷰)와 **용량당 단가(1ml/g당 가격)**, **색조 컬러 호수별 퍼스널 컬러 매칭**을 기계학습(Machine Learning)으로 종합 분석하여 청소년에게 최적의 갓성비 화장품을 추천하고 1:1로 다차원 비교(5각 레이더 차트)할 수 있는 웹 프로그램을 구현하였습니다.

## 2. 🧠 인공지능 & 기계학습(ML) 모델 설계

### ① 다차원 특성 벡터 (Feature Engineering, $X$)
1. **용량 대비 단위 가격 지수 ($f_{price}$)**: 
   - 제품 소비자가격 ÷ 용량 (원/ml or 원/g) 산출
   - 1,000원(다이소)부터 60,000원(올리브영 대용량 기획)까지 Min-Max Scaling으로 정규화
2. **화해 기준 전성분 안전도 지수 ($f_{safety}$)**: 
   - $\text{Safety Score} = \text{EWG 그린등급(\%)} - (\text{화해 20가지 주의성분} \times 20) - (\text{식약처 알레르기 주의성분} \times 10)$
3. **NLP 리뷰 감성 분석 지수 ($f_{sentiment}$)**: 
   - 화해 10대·20대 실구매자 리뷰 말뭉치 기반 긍정/부정 어휘 사전 매칭을 통한 감성 긍정 확률(0.0 ~ 1.0) 도출
4. **피부 및 선택 색상 호수 적합도 ($f_{match}$)**: 
   - 사용자 피부 타입/고민 일치도 65% + 선택된 색상 호수의 톤(봄웜, 가을웜, 여쿨, 겨쿨, 뉴트럴) 매칭 35%

---

### ② 머신러닝 알고리즘

#### 1) k-최근접 이웃 (k-Nearest Neighbors, k-NN) 분류 및 추천
사용자의 희망 입력 벡터 $U = [1.0, 1.0, 1.0, 1.0]$ 와 데이터셋 내 제품 벡터 $P_i$ 간의 **가중 유클리드 거리(Weighted Euclidean Distance)**를 계산합니다:

$$D(U, P_i) = \sqrt{w_1(1 - f_{price})^2 + w_2(1 - f_{safety})^2 + w_3(1 - f_{sentiment})^2 + w_4(1 - f_{match})^2}$$

거리 $D$를 바탕으로 유사도(Similarity, %)를 산출하여 상위 $k$개의 이웃을 추출하고 최적 추천 순위를 도출합니다:

$$\text{Similarity}(\%) = \frac{1}{1 + D} \times 100$$

#### 2) 최적 가성비 지수 (Cost-Effectiveness Index, CEI)
품질 점수(성분 + 화해 감성 리뷰 + 피부 적합도) 대비 단위용량당 가격을 머신러닝 스케일러로 표준화하여 SS등급(93점 이상), S등급(85점 이상), A등급, B등급으로 과학적 분류를 수행합니다.

## 3. ✨ 핵심 기능 및 시스템 구성

1. **실시간 학생 맞춤 가성비 화장품 추천**:
   - 용돈 예산 슬라이더(1,000원 ~ 60,000원 무제한), 피부 타입, 피부 고민(여드름/피지/속건조/홍조/모공), 퍼스널 컬러(웜/쿨/뉴트럴)를 조작하면 실시간 추론.
   - 모든 제품에 선명한 **실물 화장품 이미지** 표시 (네트워크 차단 시 자동 fallback 아이콘 탑재).
2. **색조 화장품 컬러 호수(Color Options) 인터랙션**:
   - 틴트, 블러셔, 아이섀도우, 쿠션의 상세 호수(예: 롬앤 베어그레이프, 피그피그, 쥬쥬브 / 페리페라 맘찍로즈 / 태그 쉐딩 웜·쿨 등) 스와치 칩 제공.
   - 컬러를 클릭하면 선택된 호수에 맞춰 퍼스널컬러 톤 매칭 점수와 설명이 실시간 동기화.
3. **화해(hwahae.co.kr) 연계 큐레이션**:
   - 화해 뷰티어워드 1위 뱃지, 화해 실평점(★ 4.8), 20가지 주의성분 0개 클린 포뮬러 필터, 실제 10대 솔직 리뷰 수록.
4. **화장품 다차원 1:1 비교 스튜디오 (Comparison Studio)**:
   - 비교하고 싶은 화장품을 2~4개 선택하여 **HTML5 Canvas 5각 레이더 차트(Radar Chart)**로 방사형 비교.
   - 단가 경쟁력, 전성분 안전도, 화해리뷰 만족도, 피부 적합도, 가성비 지수의 5개 축 시각화.
   - 1:1 스펙 대조 테이블 및 AI 비교 총평(최강 단가템 vs 종합 가성비템) 제공.
5. **머신러닝 연구실 (AI Lab)**:
   - $k$값 하이퍼파라미터 조절 ($k=1, 3, 5, 7$)에 따른 최근접 이웃 목록의 동적 변화 실험.
   - 4대 특성별 가중치($w_i$) 슬라이더 조작을 통한 순위 변동 탐구.
6. **수행평가 탐구 보고서**:
   - 문제정의, 특성 공학, 알고리즘 수식 모델, 결론이 담긴 보고서 및 [🖨️ 인쇄/PDF 저장] 지원.
